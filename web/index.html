Завершённые задачи автоматически удаляются сервером по TTL (см. /health → job_ttl_seconds). Выполняющуюся задачу отменить нельзя — сервер обрабатывает задачи по одной.

GigaAM Web UI — отдельный веб-сервис, проксирующий запросы к API-контейнеру. Аудио и видео декодируются на сервере через ffmpeg; сервер обрабатывает одну задачу за раз.
